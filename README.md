Официальный персональный сайт-визитка стендап-комика **Даниила Петрова**. Участник программы «Открытый микрофон» на ТНТ, дважды финалист «Камеди Баттл» и резидент Stand-Up Club #1.

🌐 **Демо-версия сайта**: [Ссылка на GitHub Pages](https://anneakhmedova.github.io/petroffwhite/)

## ✨ Особенности проекта

- 📱 **Полная адаптивность**: Корректное отображение на мобильных устройствах, планшетах и десктопах.
- 🎨 **Современный UI/UX**: Тёмная тема, градиенты, glassmorphism-эффекты и плавные анимации при скролле (Intersection Observer).
- 🎬 **Интеграция видео**: Секция с превью роликов, которые автоматически подгружают обложки с YouTube и ведут на оригинал.
- ⚡ **Высокая производительность**: Чистый Vanilla JS, отсутствие тяжелых фреймворков, оптимизированные изображения.
- 🔍 **SEO-оптимизация**: Семантическая верстка, мета-теги `description`, `viewport` и структурированные заголовки.

## 🛠 Технологический стек

- **Разметка**: HTML5 (семантические теги)
- **Стили**: CSS3 (Custom Properties, Flexbox, CSS Grid, анимации `@keyframes`)
- **Интерактивность**: Vanilla JavaScript (ES6+)
- **Иконки**: Font Awesome 6
- **Шрифты**: Google Fonts (Inter)
